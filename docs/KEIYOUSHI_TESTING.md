# Try Keiyoushi with Inkwell 0.2

This is an experimental, in-process extension host. Only the versions recorded in `VALIDATION.md` have device-test evidence; other sources may need additional compatibility work.

## Install the app

Use the **0.2 ARM64 debug APK** from the latest successful **Build Android APK** run. The old 0.1 APK does not execute extensions.

A clean GitHub runner uses a new debug signing key. If Android refuses an update over 0.1, uninstalling that old test build may be necessary. **Uninstalling deletes its library and reading data.** Stable signing is not configured yet.

## Install the first test extension

Use Keiyoushi's official listing:
https://keiyoushi.github.io/extensions/

The exact first test target is **xkcd 1.4.17**:
https://github.com/keiyoushi/extensions/releases/download/6ca40f6-0/tachiyomi-all.xkcd-v1.4.17.apk

Pinned APK file SHA-256:
`74ef6fb112925b86ec44f30624a0cb5b0451095cfc7f1a34a853132c6cc1da99`

Install it using Android's package installer. An extension stored privately inside Mihon is not a system-installed package and will not appear in Inkwell's scanner. No extension is bundled or installed automatically by Inkwell.

## Open and read

1. Open **Browse → Extensions** in Inkwell.
2. Tap rescan if the newly installed extension is not visible.
3. Expand xkcd, select **Review trust and load**, and read the permission warning and certificate identity.
4. Approve only if you trust that APK's publisher. Extension code runs with the app's permissions; it is not sandboxed.
5. Choose **xkcd / EN**.
6. Use the **Popular** tab. This extension deliberately returns an empty list for text searches; an empty search is not a loader error.
7. Open xkcd, select a chapter and read. Page position is saved on this device.

xkcd pages can include an extra text-rendered image generated by the extension. Interactive comics may require opening the source website; not every comic is a static image.

## What remains limited

- The main library still contains bundled sample titles; saving live titles into that library is not implemented.
- Custom filters, source preference screens, downloads, background updates, JavaScript and site-verification interaction are not implemented.
- API 1.6 is an experimental host target, not a blanket compatibility claim.
- Private extension import and in-app APK installation/update management are not implemented.
- Restart Inkwell after revoking trust to fully unload code the extension may already have started.

If a source fails, report the extension name/version, selected language, Android version, failing step and displayed error. Do not include passwords, cookies, tokens or private account data.
